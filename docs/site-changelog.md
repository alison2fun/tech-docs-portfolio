# Changelog

这个页面记录作品集站点本身的结构、内容和交互更新。项目文档质量自动化流水线的更新记录仍保留在 [更新记录](changelog.md)。

## v2.5.0 - 精简复盘与方法入口

发布日期：2026-08-11

### 主要改动

* 将统一入口改名为“复盘与方法”，保留原有 `/case-studies/` 路径；
* 页面只保留项目复盘和写作方法两个主体部分；
* 取消重复推荐、分类卡片和最近更新，将外部文档拆解并入写作方法；
* 保留 Changelog 文件及原有文章 URL，并同步更新站内入口文字。

## v2.4.0 - 合并复盘和方法入口

发布日期：2026-08-10

### 主要改动

* 将顶部导航中的“案例复盘”和“写作与方法”合并为一个统一入口；
* 按项目复盘、方法文章、优秀文档拆解和更新记录重组入口；
* 保留原有文章 URL，并将旧入口改为简短迁移页；
* 单独建立优秀文档拆解目录，统一收录九篇外部文档分析；
* 补充核心作品、项目复盘和方法文章之间的双向链接，同时区分已完成与整理中的内容。

## v2.3.0 - 页面职责与证据收紧

发布日期：2026-08-03

### 主要改动

* 将站点名称改为“梁卓雯｜技术文档作品集”，与四类核心作品的实际范围保持一致；
* 明确项目 03 负责展示流水线的设计、实现和验证，项目 04 负责展示同一工作流的英文任务型文档；
* 精简五篇英文页面，移除过期状态、重复说明和页面内重复样式；
* 精简硬件项目概览和 Quick Start，把资料重组与写作判断集中到案例复盘；
* 提升“配置与数据读取”的任务标题层级，压缩故障排查中的重复跳转与检查项；
* 为英文项目增加独立缩略图，并缩短首页项目卡与右侧页面目录。

## v2.2.0 - 英文核心项目与证据同步

* 新增 Documentation Quality Pipeline 英文核心项目，完成 Project Overview、Quick Start、Configure Vale、GitHub Actions 和 Troubleshooting；

发布日期：2026-07-10

* 把写作样稿从长表格改为按读者任务分类的文档索引；

## v2.0.0 - 职业化优化

发布日期：2026-07-07

### 主要改动

* 重构首页文案与入口权重，突出 Docs-as-Code 技术文档系统定位；
