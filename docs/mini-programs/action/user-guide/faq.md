# 常见问题

## 为什么拆解结果太笼统

先回到输入页，把时间、交付物和当前状态补进去，再重新生成。

可以先按这个结构修改：

> 具体任务 + 时间范围 + 当前状态或限制条件

例如，把“准备面试”改成：

> 准备明天下午的技术文档工程师面试，今天先完成一份两分钟自我介绍。

同一个任务，写得越具体，拆出来的步骤通常越容易直接开始。更多例子可以看[创建与拆解任务](create-task.md)。

## 生成的步骤太大或太细怎么办

还是回到原始任务描述，先调整范围。

如果步骤太大，可以把交付物缩小，或者把时间范围再收一点。  
如果步骤太细，说明限制给得太碎，可以减少不必要的条件，让一次行动里容纳几个紧密相关的小动作。

你可以把它理解成：不是每次结果不合适，都要推翻任务本身，很多时候只是输入范围还没有收准。

## 可以修改单个步骤吗

当前原型不支持直接编辑单个步骤。

需要调整时，请回到输入页，修改原任务后重新生成。优先补充时间、已有材料和这次不处理的内容，这样通常会比只改一句任务名称更有效。
