# 输入内容安全提醒

微步 ACTION 会把用户填写的任务描述传给微信云函数，再由云函数调用 DeepSeek，生成 5 个行动步骤。

生成完成后，任务名称、行动步骤、提示内容和完成状态会保存在微信云开发数据库的 `tasks` 集合中，用于展示任务详情和成就箱中的历史记录。

当前代码没有设置任务记录的自动过期时间。记录会继续保存在云数据库中，直到被主动清理。

当前版本也没有提供由用户主动删除单条任务记录的入口。因此，写任务时，只提供完成这次拆解真正需要的信息。

请不要输入：

- 密码、验证码和 API Key；
- 身份证号、银行卡号等敏感信息；
- 未经授权的他人隐私；
- 公司内部资料；
- 受保密协议约束的信息。

产品侧仍需确认的问题见[数据与隐私边界](../product/data-privacy-boundaries.md)。
