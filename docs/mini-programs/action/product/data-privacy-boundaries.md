# 微步 ACTION 数据与隐私边界

用户写下的任务，可能包含求职、学习、工作和生活信息。这些内容会经过 AI 服务处理，也会被保存为任务记录，因此需要把数据去向、保留方式和用户控制边界说清楚。

## 一条任务会经过哪里

当前任务数据的处理路径是：

```text
用户输入任务
→ 小程序前端
→ generatePlan 云函数
→ DeepSeek
→ 返回行动步骤
→ 写入微信云开发数据库
→ 在任务详情和成就箱中展示
```

DeepSeek 负责生成行动步骤。微信云开发数据库负责保存任务及其完成状态。

## 发送给 DeepSeek 的内容

前端会把用户填写的完整任务描述作为 `userTask` 传给 `generatePlan` 云函数。

云函数再把任务描述放入 DeepSeek 请求中，用于生成：

- 5 个行动步骤；
- 2 条提示内容。

用户主动写进任务框里的内容，会随任务描述一起进入 AI 请求。

因此，任务输入框不适合填写敏感或需要长期保密的信息。

## 云数据库保存什么

任务结果会写入微信云开发数据库的 `tasks` 集合。

根据当前数据库记录，可以确认保存的内容包括：

- 任务名称；
- 行动步骤；
- 每一步的完成状态；
- 提示内容；
- 创建时间；
- 整个任务是否已经完成。

页面还会根据任务记录展示完成数量、当前进度和历史任务。

## 数据会保存多久

当前代码中没有自动过期或定期清理逻辑。在没有人工清理或新增删除逻辑的情况下，任务记录会继续保存在云数据库中。

## 用户现在可以做什么

当前版本允许用户：

- 查看历史任务；
- 打开任务详情；
- 继续未完成的任务；
- 更新步骤完成状态。

当前版本没有提供由用户主动删除单条任务记录的入口。数据库管理员可以在云开发控制台中删除记录。

## 输入内容安全提醒

请不要在任务框中输入：

- 密码、验证码和 API Key；
- 身份证号、银行卡号等敏感信息；
- 未经授权的他人隐私；
- 公司内部资料；
- 受保密协议约束的信息。

只提供完成这次任务拆解真正需要的信息。

## 还需要确认的边界

正式发布前，还需要继续核对：

- `tasks` 集合的数据权限；
- 每条任务是否与创建者的 OpenID 关联；
- 不同用户是否只能读取自己的任务；
- DeepSeek 对请求内容的保留和使用规则；
- 日志中是否记录完整任务内容；
- 用户删除任务后，需要同时清理哪些关联数据。

其中最优先的是数据库访问权限和用户隔离。任务内容可能涉及个人计划和工作信息，不能让不同用户互相读取。

用户当前需要遵守的输入边界见[输入内容安全提醒](../user-guide/privacy.md)，完整流程见[系统流程设计](system-flow-design.md)。
