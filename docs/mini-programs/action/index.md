# 微步 ACTION：AI 任务拆解小程序

产品概览

很多时候，我们都知道自己要做什么，却迟迟落不下第一步。任务写在待办列表里，还是太大；想到要一口气做完，又很难开始。

微步 ACTION 就是从这个卡点出发做的一款小程序原型。

用户输入想完成的任务，或不想面对却必须去做的事情，系统会把它拆成 5 个可以立马行动的微小步骤。完成一步，进度就往前走一点。

## 用户遇到的问题

这个产品想处理的，是“开始之前”的卡顿：

* 目标太大，不知道先做什么；
* 任务描述太模糊，很难判断下一步；
* 明明已经做了一部分，却看不出自己推进了多少。

准备面试、写文章、整理汇报和复习考试时，我都反复碰到过这种情况。用户知道最终要完成什么，缺的是一个足够具体、能立刻动手的起点。

## 产品怎样回应

它的核心流程很短：

```text
输入任务
→ 生成 5 个行动步骤
→ 勾选已经完成的步骤
→ 查看进度变化
```

页面能够生成步骤，只是用户得到了一组结果，而当 TA 勾选一步并看到进度变化后，才真正理解这个产品怎样工作。

## 我在这个项目中完成的工作

我把“无法开始一个大任务”这个用户问题，整理成了一条更完整的产品路径：从输入、拆解，到勾选和进度变化。

围绕这条路径，我完成了：

* 产品问题、用户故事和功能边界的整理；
* PRD、原型快速体验和日常操作文档；
* 系统流程设计与任务拆解云函数调用说明；
* 页面文案和原型截图说明；
* MkDocs Material 文档集的信息架构。

写文档的过程，也把一些原来被我忽略的问题推到了我面前：进度保存在哪里、用户能不能删除记录、哪些能力已经做成，哪些还只是设计目标。这些问题现在被集中放进了后面的产品设计页面。
