# 小程序产品总览

这部分记录了我做的三个小程序。它们的想法都源于我自身和观察到的小需求。利用 AI，我将它们做成了可以使用的原型，没有宣传，现在也积累了 300+ 用户。

作为作品集的一部分，我开始为它们补充用户手册、PRD、页面流程和版本记录等文档。在这个过程中，我才更清楚地意识到，按钮能用只是产品的开始，后面还有很多问题要继续说明。这个过程也帮助我想清楚：每个小程序在解决什么问题、页面怎样工作、还缺什么、我可以怎样把这些内容整理出来。

## 微步 ACTION：AI 任务拆解小程序

<span class="doc-badge doc-badge--version">版本 · v1.0.0</span>
<span class="doc-badge doc-badge--style">风格 · 故事手帐</span>

核心功能：把用户输入的模糊目标拆成 5 个微小、可以立即开始的步骤。

主要交互：

- 输入任务描述，补充时间范围和当前状态；
- AI 生成 5 个可勾选的任务步骤；
- 勾选已完成步骤，查看进度变化；
- 完成全部步骤后，进入成就反馈。

目标用户：知道自己要做什么，但总是卡在“怎么开始”的人。

## 照片换底色小程序

<span class="doc-badge doc-badge--version">版本 · v1.0.0</span>
<span class="doc-badge doc-badge--style">风格 · 故事手帐</span>

核心功能：快速替换照片背景颜色，完成简单的证件照或轻量图像处理。

主要交互：

- 上传照片；
- 选择背景颜色；
- 预览替换效果；
- 保存处理后的图片。

目标用户：需要快速更换照片背景，或临时处理图片底色的普通用户。

## 波点拼接效果小程序

<span class="doc-badge doc-badge--version">版本 · v1.0.0</span>
<span class="doc-badge doc-badge--style">风格 · 故事手帐</span>

核心功能：把图片处理成波点拼接效果，做出比较轻量的趣味图像。

主要交互：

- 上传图片；
- 调整波点大小和间距；
- 生成波点拼接效果；
- 保存或分享成品。

目标用户：对图像趣味效果感兴趣，想快速做一张轻量风格图片的用户。
