# 从一页说明书到产品文档集

这是一篇简短的案例入口。完整复盘还需要在后续阶段补写，这里先连接已经完成的页面和可以核对的结构变化。

旧版“用户文档”同时承担产品介绍、快速开始、日常操作、常见问题和作品说明。当前文档集已经把内容拆成三组：

- **用户指南**：帮助用户体验原型、创建任务、管理进度和处理常见问题；
- **产品设计**：记录 PRD、系统流程、云函数调用和数据隐私边界；
- **迭代与计划**：记录原型完成过程和后续判断。

旧版页面仍作为迁移入口保留，原有地址不会直接失效。
